# Formulario de Inscripción a Curso

Aplicación web del tipo formulario hecha con REACT como parte de la enseñansa en la cursada de Introducción al Desarrollo Web.

## ¿Qué hace?

Permite a un usuario inscribirse a un curso completando un formulario con los siguientes campos:

- Nombre y apellido (solo letras)
- DNI (solo números)
- Email
- Curso (React JS, JavaScript o HTML y CSS)
- Modalidad (Online o Presencial)

Al enviar va a validar que todos los campos obligatorios esten completos y que el nombre y el DNI tengan el formato correcto.

## Tecnologías usadas

- HTML — estructura del formulario (etiquetas dentro de JSX)
- CSS — estilos, colores, responsive con media queries
- JavaScript — lógica, validaciones con "if" y expresiones regulares
- React JS — componente "Formulario" con "useState" y manejo de eventos
- Create React App — entorno de desarrollo
- Node.js v24.18.0 — versión utilizada
